# API索引表

- 章节头标注类型与端侧，条目格式为「英文名 一句话描述」，枚举值章节的条目不是接口
- 定位到名称后，把本次要用的接口在同一条消息里并行调用 get_api_detail（单次往返取回全部签名）
- 跨端同名接口在客户端/服务端章节各有一条
- 描述里的 markdown 链接是相对 `D:/mod-debug-bridge/docs/` 的文档路径（mcguide 官方教程镜像），anchor 是文档内节名；查该主题细节时拼上前缀 grep 或读该文件
